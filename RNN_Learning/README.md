# RNN Learning — Conceptual Chapters

This folder contains conceptual notes studied alongside the IMDb Movie Review Sentiment Analysis project. The chapters move from recurrent-network fundamentals to their use in sentiment classification.

## Chapters

| Chapter | Topic |
|---|---|
| [01 — Introduction to RNNs](01_Introduction_to_RNNs.md) | Sequential data and RNN fundamentals |
| [02 — RNN Architecture](02_RNN_Architecture.md) | Inputs, hidden states, outputs, and weight sharing |
| [03 — Training RNNs](03_Training_RNNs.md) | Forward propagation, BPTT, and gradient problems |
| [04 — LSTM Architecture](04_LSTM_Architecture.md) | Cell state, gates, and long-term dependencies |
| [05 — RNNs for Sentiment Analysis](05_RNNs_for_Sentiment_Analysis.md) | Many-to-one classification and project workflow |

## Suggested learning order

Read the chapters in numerical order. Each chapter includes explanations, equations, examples, and quick revision questions.

> These are conceptual learning notes. They are separate from the original project notebook and do not change its implementation or reported results.

## Project connection

The repository's original notebook remains the original TF-IDF + PyTorch RNN experiment. These chapters explain RNN and LSTM concepts; they do not claim that the original notebook implements a word-by-word sequential RNN or an LSTM.
